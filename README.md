# Speech to Text (STT) Project
# 🎙️ Speech-to-Text + Formality Detection

This project converts speech audio to text and detects whether the text is **Formal** or **Informal**.

## 🚀 Deployment Link
👉 [Click here to try the app](https://speechtotextproject-cqornbckvkcgwkyfduaja8.streamlit.app/)

## 📂 Project Structure
- stt.py → Main speech-to-text + formality detection logic
- app.py → Streamlit app for deployment
- requirements.txt → Dependencies list
- examples/ → Sample audio files
- README.md → Documentation & deployment link

Usage:
1. Put your audio in examples/sample.wav
2. Create virtualenv, activate it, then:
   pip install -r requirements.txt
3. Run:
   python stt.py
